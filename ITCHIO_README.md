🚀 GALACTIC RING: CANNON

A VS-like incremental space shooter. Choose your pilot, level up, collect upgrades, and survive boss encounters in the depths of space.

⚠️ FLASHING LIGHTS - This game contains animated visual effects.

════════════════════════════════════════

🎮 HOW TO PLAY

WASD / Arrow Keys — Move
Space — Dodge roll
1-3 — Select upgrades when leveling up
M — Toggle sound
N — Skip music track
P / ESC — Pause

════════════════════════════════════════

🌊 GAME LOOP

1. Kill enemies → Collect XP orbs
2. Level up → Choose from 3 random upgrades
3. Survive waves → Boss spawns every ~60 seconds
4. Defeat boss → Continue run OR start fresh
5. Earn stars → Buy permanent upgrades

Bosses scale with each encounter. How far can you go?

════════════════════════════════════════

💡 TIPS

• Magnet Range is OP early — safer XP collection
• Dodge has a cooldown — save it for emergencies
• Orbitals provide passive damage while you focus on dodging
• Chain Lightning stacks with Stormcaller's built-in chains
• Bosses phase at 70%, 40%, 15% HP — attacks change!
