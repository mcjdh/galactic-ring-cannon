════════════════════════════════════════
☠️ BOSS SYSTEM
════════════════════════════════════════

LOOP STRUCTURE
  • GRC1: 3 bosses → Win screen → Game over
  • GRC2: Defeat 4 bosses → Choose: Continue or Restart
  • Every 4th boss is a MEGA BOSS (+50% HP, larger, more minions)

BOSS SCALING
  • Boss 1: 1.0x
  • Boss 2: 1.2x
  • Boss 3: 1.4x
  • Boss 4 (Mega): 1.6x × 1.5x
  • Boss 5+: +20% each

4-PHASE BATTLES
  • Phase 1 (100-70%): Basic attacks
  • Phase 2 (70-40%): Shield mechanic + faster attacks
  • Phase 3 (40-15%): Teleportation + enhanced minion spawning
  • Phase 4 (15-0%): Damage zones + rage mode

REWARDS
  • 10 Star Tokens per boss
  • 15% max HP heal on victory
  • Perfect kill (>90% HP): +50% XP, 15% bonus heal, 2s invuln
